# VÉRO

Editorial e-commerce for **VÉRO** — weaves, couch bags, colognes, and plain t-shirts.

## Local development

```bash
cd vero-store
npm install
npm run dev
```

## Product photos

Drop images into `vero-store/public/products/`, then set each product's `image` path in `vero-store/src/data/products.ts`.
